Before you write in

A few things that help a message get answered faster:

  • Game recommendations — mention what kind of experience it offers and roughly how long it takes to finish. That's usually enough to bump it up the backlog.
  • Corrections — link the exact post and paragraph. Every fix gets credited in the post itself once it's made.
  • Collaborations — GiB doesn't run sponsored posts, but is always open to swapping links with other honest, independent game blogs.
